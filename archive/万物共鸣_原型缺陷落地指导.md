# 万物共鸣 · 交互原型缺陷落地指导

> 本文档供 LLM 辅助修复使用。每个要点格式：**现状 → 目标 → 验收**。
> 修复对象：`万物共鸣_交互原型.html`（单文件，约 797 行）

## 缺陷一：粒子系统消失（文字形态无法成形）

### 现状

p5.js 在 `setup()` 阶段同步调用 `build()`，`build()` 内部通过 `sample()` 函数将中文字符渲染到离屏 `pg` buffer 上，再扫描像素以提取字形点位。问题出在字体：`pg.textFont('STSong,SimSun,serif')` 依赖系统字体加载，而 `setup()` 执行时 WebFont 尚未就绪。浏览器回退到默认字体，字形轮廓与预期不符，`px > 100` 的像素采样结果极少，`pts` 数组接近空，粒子的 `tx/ty` 目标点全部堆叠在默认位置，视觉上粒子存在但永远分散、无法聚合成汉字轮廓。

另有一个次要问题：`setup()` 中 `document.getElementById('cvs').replaceWith(c.elt)` 将原始 `<canvas id="cvs">` 替换为 `id="p5c"` 的新 canvas，CSS 中 `#cvs` 的 `width:100vw; height:100vh; z-index:0; pointer-events:none` 不再对新元素生效，只保留了 JS 内联写入的 `position:fixed; top:0; left:0`，可能导致画布尺寸异常或点击穿透失效。

### 目标

1. 保证字体就绪后再采样：使用 `document.fonts.ready` Promise 或 `FontFace` API 等待 `STSong`/`SimSun` 加载完成，再调用 `build()`，确保中文字符能在 `pg` buffer 中正确光栅化。
2. 修复 canvas 样式继承：替换后的 canvas 元素应补全原始 CSS 规则，或直接在 JS 中对 `c.elt` 设置完整的内联样式（`width:100vw; height:100vh; z-index:0; pointer-events:none`）。

### 验收

- 打开原型，滚动至 S4（濒危 5 种）段，粒子在 3 秒内聚合并清晰呈现「雪豹」「朱鹮」「扬子鳄」「长江江豚」「华南虎」五组汉字轮廓。
- 鼠标移动或麦克风输入时，粒子从字形散开；停止干扰后，粒子重新收拢回汉字形态。
- 调整浏览器窗口大小（`windowResized` 触发），粒子仍能正确重建，不退化为随机散点。
- 在 Chrome DevTools → Computed → `#p5c`（或画布元素）验证：`width` 等于视口宽，`height` 等于视口高，`pointer-events: none`。

## 缺陷二：开启声音后出现持续高频噪音

### 现状

`updateSound()` 在 p5.js 的 `draw()` 中每帧（约 60fps）调用一次，其中对各物种振荡器执行：

```js
oscillators[i].osc.frequency.setTargetAtTime(
  FREQ[i] * (0.95 + v*0.1 + Math.random()*0.02),
  audioCtx.currentTime,
  0.3  // timeConstant
);
```

关键问题：`Math.random()` 每帧生成一个新随机值，导致目标频率以 60Hz 的速率随机抖动。`timeConstant=0.3` 的指数平滑无法跟上 16ms 一次的随机更新，振荡器频率实际上在目标频率附近快速颤抖。

对于 `FREQ[3] = 1800`（长江江豚，代表其高频声呐），频率在 `1710~1836 Hz` 之间高速随机跳变，产生刺耳的频率调制噪声，听感类似耳鸣或电流干扰音。其他物种（如 `FREQ[0]=280` 三角波、`FREQ[2]=90` 锯齿波）同样存在相同问题，锯齿波的谐波叠加进一步加剧噪音感。

### 目标

1. **移除帧级随机频率抖动**：将 `Math.random()` 替换为基于 p5 noise 或低频 LFO 的平滑调制，确保频率变化速率不超过 2~4Hz，呈现自然的颤音效果而非噪声。
2. **降低或替换高频振荡器**：长江江豚的 1800Hz 合成音在人耳中极为刺耳，应降至 400~600Hz 区间，或改为使用 Web Audio API 的 `BiquadFilter`（低通）对现有频率进行滤波，保留声学象征意义的同时去除不适感。
3. **振荡器增益上限保护**：对每个振荡器的 `gain.gain` 值添加硬上限（如 `Math.min(target, 0.08)`），防止 `vit` 值在边界条件下导致增益意外超标。

### 验收

- 点击「♪ 声音：开」后，任意滚动位置不出现持续的刺耳高频音或电流噪声。
- 在 S4（濒危段）静置 10 秒，背景声音应呈现安静、有机的复调质感，各物种音色可辨别但不互相干扰。
- 使用浏览器 DevTools → Performance → Audio 或外部频谱分析工具验证：任意时刻振荡器频率变化速率 ≤ 4Hz，无 1kHz 以上的尖峰脉冲。
- 用鼠标快速移动触发 `dLv` 干扰，城市噪声（`aud-city`）应平滑淡入，无点击爆音（click artifact）。

## 缺陷三（低优先级）：白鳍豚音频文件格式不一致

### 现状

`声音/` 目录中存在 `Baiji, Yangtze River Dolphin.mp4`（视频容器，含音频流）和 `白鳍豚.mp3`（MP3）两个文件。HTML 中引用的是 `白鳍豚.mp3`，目前可正常加载，但 `.mp4` 文件的存在可能产生混淆，未来重构时可能误引用导致音频无声。

### 目标

确认 `白鳍豚.mp3` 文件内容完整且音质可接受（白鳍豚历史录音稀缺，若 `.mp4` 中有更完整的录音片段，应从中提取 MP3 并替换）；删除或归档多余的 `.mp4` 文件，保持资源目录整洁。

### 验收

- `声音/` 目录中引用的音频文件均为 `.mp3` 或 `.ogg` 格式，无冗余 `.mp4`。
- S3（已消失段）开启声音后，白鳍豚的历史录音可正常淡入播放，音质清晰无杂音。
